# 📋 Playbook générique
## 🔎 Investigation
- Analyser les alertes jointes (Timeline), le contexte hôte / utilisateur
## 🛑 Confinement
- Isoler l'hôte ou le compte si compromission avérée
## 🧹 Remédiation
- Corriger la cause, durcir la configuration

## ✅ Clôture
- Documenter les constats dans les commentaires du Case
- Classer : **vrai positif** / **faux positif** / **test**
- Passer le Case en *Closed* (les alertes liées passent en *Closed*)
